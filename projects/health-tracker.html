Health Tracker with STM32 and LoRa

A wearable animal-health tracking prototype for farmers and pet owners, combining heart-rate and gait sensing with long-range LoRa reporting.

C STM32 LoRa CubeIDE Sensors
View the GitHub repository Watch the demo

Short demonstration of the health-tracking prototype.

Overview

The goal was to prototype an animal health tracking tool that could help farmers and pet owners monitor an animal's heart rate and movement. The wearable node uses an Adafruit LoRa module, an MPU6050 accelerometer and gyroscope, and a MAX30102 optical heart-rate sensor. If developed beyond the prototype stage, the electronics would be consolidated into a single compact PCB and packaged for comfortable use on an animal.

Implementation

I implemented the wireless communication and receiver/display side of the prototype, and integrated it with Matthew's sensor pipeline. The RFM9x driver was adapted from existing Arduino-oriented LoRa code and rewritten around the STM32 HAL SPI interface. It handles module reset and version checks, LoRa mode configuration, FIFO access, transmit/receive state changes, interrupt flags, and packet completion.

On the transmitting STM32, I defined the application payload and packed the computed values into fixed-width fields: heart rate, acceleration magnitude, and step count. The packet is sent periodically over LoRa using the RFM9x FIFO. On the receiving STM32, I implemented the matching receive path, unpacked the multi-byte values, and formatted them over UART so a laptop could act as the display device. This established the end-to-end flow from sensor readings to a remotely viewable health and activity summary.

Matthew Lee implemented the heart-rate and IMU hardware integration, sensor initialization, data acquisition, and signal processing.

Bandwidth and power analysis

These are theoretical estimates based on the demo configuration, not a production battery-life measurement.

Module Demo rate or time Estimated active time
IMU over I2C 1100 samples/s, 105.6 kbps 0.264 s/s
IR sensor over I2C 32 samples/s, 1024 bps 0.00256 s/s
LoRa over SPI 800 bits/s 0.000008 s/s
CMSIS FFT 224 microseconds 0.000224 s/s

The combined estimate is 0.266792 seconds of active CPU time per second, or 26.7% active and 73.3% available for sleep. Using the report's 3.3 V estimates, demo CPU power was 46 mA x 3.3 V = 0.1518 W. A sleep current of 12.46 mA would save approximately 0.11 W, a theoretical 73% reduction in CPU power consumption.

Source references

The project code was based on or adapted from the following external repositories. The LoRa interface was substantially rewritten for the STM32 platform.

  1. RadioHead by Hallard, used as a reference for packet-radio behavior.
  2. STM32 HAL RFM95 by Henriheimann, used as a reference for the RFM95/RFM9x driver.
  3. stm32-max30102 by eepj, used as a reference for the MAX30102 interface.
  4. MPU6050 by svenikea, used as a reference for the IMU interface.

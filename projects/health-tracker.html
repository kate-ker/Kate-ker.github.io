Health Tracker with STM32 and LoRa

An embedded health tracker built in C on an STM32 microcontroller, with LoRa for wireless reporting and onboard heart-rate and motion sensing.

C STM32 LoRa CubeIDE Sensors

Overview

This project implements a compact health-tracking node that collects physiological and motion data and transmits it over a LoRa link. Firmware was written in C and developed in CubeIDE, targeting an STM32 microcontroller.

What I built

  • STM32 firmware in C for sensor bring-up, sampling, and packetization.
  • Integration of a LoRa module for wireless communication.
  • Heart-rate and accelerometer sensing on a single embedded platform.

The goal was a working end-to-end path: sense, process on-device, and send, rather than a simulation-only prototype.
